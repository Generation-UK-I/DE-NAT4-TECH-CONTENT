### Shellassic Park Exercise 3
---

Do your best to complete the following exercise in the allotted time. Take a look at the resource library for additional infoprmation to try! Good luck and have fun! 

1. Write a script that checks a person's age (given as an argument). The script should:
- Print "You are a minor" if the age is less than 18.
- Print "You are an adult" if the age is 18 or older but less than 65.
- Print "You are a senior" if the age is 65 or older.

2. Write a script that compares two strings (taken as arguments). The script should:
- Print "The strings are equal" if the strings are the same.
- Print "The strings are different" if the strings are not the same.

Challenge: Add a check to ensure the user enters two arguments. If not, print "Please provide two strings."

3. Write a script that takes a number as an argument and checks if it is even or odd. The script should print:
- "The number is even" if the number is divisible by 2
- "The number is odd" if the number is not divisible by 2.

Challenge: Add a check to ensure the argument is a valid number. If it’s not a valid number, print "Please enter a valid number."

4. Write a script that prompts the user to input their favorite dinosaur. If the input matches one of the following, print a message:

- "T-Rex: King of Dinosaurs!"
- "Triceratops: The Mighty Herbivore!"
- "Velociraptor: Smart and Agile!"
- Otherwise, print "That's an interesting dinosaur!"
