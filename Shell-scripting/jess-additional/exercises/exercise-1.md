### Shellassic Park Exercise 1
---
Do your best to complete the following exercise in the allotted time. Take a look at the resource library for additional information to try! Good luck and have fun! 

1. Write a shell script that prints “Shell Scripting is Fun!” on the screen.

2. Modify the shell script from exercise 1 to include a variable. The variable will hold the contents of the message “Shell Scripting is Fun!”

3. Write a script called welcome_dino.sh that:

- Defines a variable called DINOSAUR and sets it to "Velociraptor".
- Echoes a welcome message using the variable.
- Prints the current date and time.

4. In the terminal, define a variable. Such as: 

```bash
DINO="Triceratops"
```

Then use it in a command within the terminal. Such as:

```bash
echo "Today's dinosaur is: $DINO"
```

5. Store the output of the command “hostname” in a variable. Display “This script is running on _.” where “_” is the output of the “hostname” command.


6. Store the following quotes in a variable, and their speakers in another variable. Print out the quote and the full name of who said it: 

- "Life... finds a way." - Dr. Ian Malcolm
- "Welcome... to Jurassic Park." - John Hammond
- "Oh help us, we're in the hands of engineers." - Dr. Ian Malcolm
- "It's a UNIX system! I know this!" - Lex
