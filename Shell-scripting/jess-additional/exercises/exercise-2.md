Do your best to complete the following exercise in the allotted time. Take a look at the resource library for additional infoprmation to try! Good luck and have fun! 

1. Follow the instructions:
- Use read to get the ranger’s name from the user.
- Store it in a variable called RANGER.

2. Follow the instructions:
- Create a script that uses two arguments: One for a ranger name and another for a dinosaur type
