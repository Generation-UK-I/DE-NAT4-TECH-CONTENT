### Shellassic Park Exercise 3
---
Do your best to complete the following exercise in the allotted time. Take a look at the resource library for additional infoprmation to try! Good luck and have fun! 

1. Follow the prompts: 
- create a script called dino_age_checker.sh.
- At the start of the script, prompt the user to input the dinosaur's name.
- Use a conditional to check if the dinosaur is "T-Rex". If it is, print: "T-Rex is 68 million years old!".
- If the dinosaur is "Stegosaurus", print: "Stegosaurus is 155 million years old!".
- If the dinosaur is neither of the above, print: "We don't have information on that dinosaur."

2. Follow the prompts: 
- Create a script called dino_age_counter.sh
- Define an array with dinosaur names (e.g., dinos=("T-Rex" "Stegosaurus" "Velociraptor")).
- Use a for loop to iterate over each dinosaur in the array
- For each dinosaur, check its age using a conditional (similar to the previous exercise).
- Print each dinosaur’s name and age in the format: "The [Dinosaur] lived [Age] million years ago."

3. Follow the prompts: 
- Create a script called dino_egg_countdown.sh.
- Start with a variable egg_count set to 10.
- Use a while loop to countdown the eggs.
- After each countdown, prompt the user with: "Do you want to continue counting down? (yes/no)".
- If the user types "no", the countdown should stop, and the script should end with "Dino egg countdown complete!"
- If the user types "yes", the countdown continues.

Sample output to help:

```bash
10 eggs left
Do you want to continue counting down? (yes/no): yes
9 eggs left
Do you want to continue counting down? (yes/no): yes
8 eggs left
Do you want to continue counting down? (yes/no): no
Dino egg countdown complete!
```
