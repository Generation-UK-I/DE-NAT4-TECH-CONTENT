# Shell Scripting

Introduction to bash scripting.

The session works well with code-along examples presented as you go for all the technical slides (which is most of them).

## Overview

- An Introduction to Shell Scripting
- Why Shell Scripting is Used
- Arguments
- Variables and Environment Variables
- Conditionals and Loops

## Timings

- This session is timetabled for 2 blocks at 1.5 hrs each
- Without mini show-and-tells or demos of each topic there is only about 2 hours of material so add these in as per the "Session" section below
- The formative assessments occur during this and are included in that timing
- The exercises for this session (done in breakouts) are also included in that time

## Assessments

To check the learner progress in this session we have:

- Emoji checks at the end of key sections
- Exercise on making a conditional script
