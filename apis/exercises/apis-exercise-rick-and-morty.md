# Calling an API

Go here: https://rickandmortyapi.com/documentation/#rest

- Utilise Postman to make the API calls below.

For each, make a request to the API to...

1. Get the first set of characters (page 1)
1. Get the second set of characters, using a filter query
1. Get one character using a path
1. Get multiple characters using a path
1. Find the character with the name `Rick`, using a filter query
1. Find the character with the name `Baby Legs` and is still alive, using a filter query
