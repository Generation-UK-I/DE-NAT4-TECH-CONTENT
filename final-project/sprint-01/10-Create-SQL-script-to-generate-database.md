# Create SQL script to generate database

## Description

We should store a SQL script in our repository so that each member can create the same schema for our data.

You will need:

- One or more *.sql files for the tables in your schema
- Have the Postgres container load these on start-up via a volume-mount
  - They need to go in your `databases\db-scripts` folder

## User Story

**As a** developer
**I want to** automate the creation of a database schema
**So that** I don't have to set it up manually
