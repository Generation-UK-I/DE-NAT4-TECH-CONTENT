# Project Initiation Tasks – Team Based 

## Project Setup (things to think about)

- Decide Team Name- Based on coffee or cafés. When decided, put Team Name into the main Teams chat.
- Scrum Master who/when for each week of the rest of course  
- Meetings/Standups throughout each sprint – How will these be structured?  

## Decide your Ways of Working

- GIT Setup - How Who, ReadMe Structure and updating, branch names
- Project directory structure
- Project naming conventions
- Trello/Planner Lists/Tickets/Layout - How

## Things to think about for the whole project

- How are you going to use Comments in your Code
- How will you share feedback with each other
- How will you communicate on your project channel
- When will Daily Standups/Team Meetings take place
- Do you have a Scrum Master assigned for each Project Sprint
- As a team, how will you delegate tasks/actions
- Tracking project progress – Trello/Planner – Planning, Notes, documentation
- Customer/Stake Holder - Clarify Requirements- (When, How Recorded)
- Weekly Project presentation – Creating, Sharing, Delivering
- What is your overall Solution
- Do you have a minimal ETL Pipeline version, solution
- If you are doing a code demo, who and how
- How are you ging to use GIT as a team
- Project Plans/Documentation -  
- Daily Briefing
- Retro
- Code Freeze, when at what points

## Things to think about for Pre Project-Backlog

- Create Elevator Pitch
- Agree Importance
- Define Scope/MOSCOW
- Define Success/Definition of Done
- Define MVP
- The Approach
