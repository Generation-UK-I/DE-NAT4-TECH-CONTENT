# Extract data from CSV file

## Description

Our client has given us an example CSV file for the type of data we will be dealing with. As part of the PoC (Proof of Concept) stage we can use this file to create our Extract stage of the pipeline, by extracting the data in from the file in python.

You will need

- Sample CSV file (large) from the client (Instructors)
- Make a cut-down CSV wit e.g. 5-10 lines for quicker testing and feedback
- Python code to load and parse the file into rows & columns

## User Story

**As a** product owner
**I want** to prove that we can extract data from a CSV file
**So that** the data is in a state that can be transformed
