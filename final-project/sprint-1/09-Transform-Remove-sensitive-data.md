# Transform - Remove sensitive data

## Description

The data that we will be dealing with contains sensitive data, which comes in the form of debit/credit card long numbers and customer names. We need to ensure this data is removed before we store it.

## User Story

**As a** customer
**I want** to ensure that my personally identifiable information is not being stored
**So that** my data is secure

Your instructor will distribute an example of a .csv from SuperCafe
