# Setup Grafana Infrastructure

## Description

- Cloudformation samples for setting up EC2 / grafana is also included in the aws-08-cfn-ec2 module from AWS Week
- Create an EC2 with Cloudformation
- Use userdata with Cloudformation to install docker and run grafana
- Change the Admin password to a proper one and put it in someone's Password manager
- Add grafana login for each person and ensure a proper password is set, and saved in your Password Managers

Also you can see additional instructions in the monitoring/examples/final-project-grafana-setup.md file (after you have had this session delivered!):

- Need to map port 80 to 3000.
- Use HTTP instead of HTTPS.
- default grafana username + password: admin/admin

Cloudformation example for setting up EC2 / grafana is also included in aws-08-cfn-ec2 module from AWS Week.
